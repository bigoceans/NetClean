## 🌐 站点支持列表

脚本通过油猴 `@match` 静态匹配下列站点，**未列出的网站**会通过 `inHost()` 守卫启动后立即早退（近零开销）：

### 搜索引擎
- `*.baidu.com`（含首页 + 搜索 + 知道 + 文库 + 贴吧 + 好看视频等子域）
- `haokan.baidu.com`（百度好看视频）
- `*.google.com` / `*.google.com.hk`
- `*.bing.com`
- `*.so.com`（360 搜索）
- `*.yandex.com`

### 内容社区
- `*.zhihu.com`（知乎）
- `*.douban.com`（豆瓣）
- `*.weibo.com`（微博）
- `*.bilibili.com`（B 站）
- `*.csdn.net`（CSDN）
- `mp.weixin.qq.com`（微信公众号文章）
- `www.52pojie.cn`（吾爱破解论坛）

### 视频
- `*.youtube.com`
- `*.youku.com`（优酷）
- `v.qq.com`（腾讯视频）
- `*.bilibili.com`（B 站）

### 社交
- `twitter.com`
- `x.com`

### 兜底
- `*://*/*`（所有网站，配合启动早退机制零开销）

> ℹ️ **为什么保留 `*://*/*`？** 它不是冗余匹配：`yandex.com` 支持与「仅在名单内网站运行」的早退兜底都依赖它（油猴 `@match` 是静态元数据，无法运行时切换）。脚本未命中 `inHost()` 守卫时会在启动后立即早退，近零开销。
>
> v1.0.10 起已移除 `file:///*`（本地 HTML 调试用，脚本无任何本地文件功能，且属 GF 代码规则里最易被要求删除的匹配）。

> 💡 **新增站点支持**：在脚本里加一个 `@match` + `function processXxx()` 处理器即可。

## 🎛️ 设置面板详解

脚本设置面板采用**安东蓝风格** shadow-DOM 容器（`#zk-set-cleaner-settings`），不污染页面 DOM。左栏按功能域分为 **9 个分类**（可拖拽重排，顺序会记住；「关于」固定收尾）：

| 分类 | 图标 | 主要内容 |
|------|------|----------|
| 净化增强 | 🛡 | ① 通用防护（护眼 / 暗黑 / 快捷键开关）② 搜索引擎广告过滤 ③ 搜索引擎美化增强 ④ 视频平台广告过滤 ⑤ 视频平台增强与下载 ⑥ 社区内容广告与登录墙 ⑦ 社区内容增强 |
| 验证码识别 | 🔑 | ① 基础开关 ② 识别引擎与凭证（接口默认留空，不发起任何外部请求）③ 智能与防护 |
| 划词搜索 | ✏️ | 总开关、翻译引擎选择（默认 iciba，可选 Google / DeepL / 百度 / 自定义）、打开链接行为 |
| 视频下载 | 📥 | 视频下载站点管理（支持批量导入站点） |
| 性能与高级 | ⚡ | 性能模式、统计与显示（拦截计数角标）等 |
| 名单管理 | 📋 | **5 份名单集中管理**：① 站点级 · 生效范围（**一个模式单选 + 一份名单**）、② 验证码级（自动扫描站点 / 跳过识别站点）、③ 内容级（屏蔽网址 / 屏蔽关键词，与内容屏蔽总开关同卡）。全部支持 **txt / csv 批量导入 + 剪贴板粘贴** |
| 快捷键 | ⌨️ | 全局快捷键、YouTube 视频旋转/翻转 |
| 配置同步 | ⚙️ | WebDAV 云端配置同步、导入 / 导出配置、🕘 配置历史回滚 |
| 关于 | ℹ️ | 版本号、产品简介、隐私声明、免责声明、问题反馈（GreasyFork / GitHub） |

> 📋 **名单集中在哪里？** 5 份名单已统一收拢到「名单管理」分类。原「净化增强 / 验证码识别 / 性能与高级」里的 3 处迁移说明卡片 + 跳转按钮已在 **v1.0.9 代码层整体移除**（v1.0.8 是过渡版，过渡期满即收回）；用户想找名单直接点左栏「📋 名单管理」。

### 名单批量导入（v1.0.8 新增）

5 份名单均支持三种录入方式，适合「一次添加很多条」：

1. **手动逐条添加**：原有输入框 + 「添加」按钮不变
2. **多行粘贴 / 剪贴板**：点「批量导入」展开文本框，直接 `Ctrl+V` 粘贴多行；或点「从剪贴板粘贴」一键读取（需浏览器授权，被拒时给出降级引导）
3. **文件导入**：选择或**拖入** `.txt` / `.csv` / `.tsv`（≤2MB，UTF-8）

智能处理规则：

- **一行一个**，也支持逗号 / 分号 / Tab 分隔；`#` 开头的行忽略（可用于写注释）
- **域名类自动归一化**：`https://www.icbc.com.cn/path?x=1` → `icbc.com.cn`
- **CSV 表格自动识别**：多列行占比 ≥60% 时判定为表格，自动跳过表头行（`url` / `网址` / `关键词` 等）、只取第一列
- **含 `://` 的行不按逗号拆**，URL 里的逗号不会被误切
- **实时预览计数**：已识别 N 条（含已在名单中 / 已归一化 / 已跳过表头）
- **聚合确认**：过短条目、可能整站失效的「致命条目」各只弹一次汇总确认；< 2 字关键词直接硬拦
- 单份名单上限 999 条；导入结果 5 秒内可「撤销」精确回滚

## 🌗 护眼模式（科学诚实版）

> ⚠️ **重要诚实声明**：本脚本的护眼模式**不改变屏幕蓝光发射量**。如需真正降蓝光，请开启操作系统级护眼模式（Windows Night Light / macOS Night Shift / f.lux）。

### 实际起作用的两层

#### 1. 视觉柔和层（multiply 暖色蒙版）
- 全屏 `position:fixed;z-index:2147483640;mix-blend-mode:multiply` 暖色蒙版
- 颜色：选自 5 种 Kindle/Night Shift/f.lux 经典「夜览配色」（羊皮纸黄/暖黄/米黄/淡橄榄绿/暖橙）
- 强度：三档 alpha 系数（柔和 .16 / 标准 .26 / 增强 .38）
- **原理**：multiply 是「颜色相乘」视觉变换，白像素 × 暖色 = 暖色，**绝不反色**，**不影响视频**

#### 2. 行为护眼层（20-20-20 休息提醒）
- 每 20 分钟 toast 提醒「远眺 20 英尺（6 米）外的物体 20 秒」
- 这是**美国眼科学会（AAO）公认最有效的护眼手段**
- 独立的静默开关 `baidueyerest`，可单独关闭

### 三种护眼方案对比

| 方案 | 降蓝光 | 视觉柔和 | 视频反色 | 适用 |
|---|---|---|---|---|
| **本脚本 multiply 蒙版** | ❌ | ✅ | ❌ | 阅读为主 |
| **OS Night Light / f.lux** | ✅ | 部分 | ❌ | 全场景 |
| **OS Night Light + 本脚本** | ✅ | ✅ | ❌ | **推荐组合** |

## 🎬 视频功能

### 视频倍速
- 全站 `<video>` 播放倍速：设置面板内拖动滑块调节，范围 **0.1x~16x，1x 位于正中间**（左滑调慢、右滑调快），右侧「1x」按钮一键复位
- **视频倍速悬浮球**：开启后自动识别当前页是否在播放视频，在页面角落显示可拖动的小球，点开即可调倍速 / 切静默播放 / 恢复 1x；无视频时半透明待机，位置自动记忆
- 检测**穿透 shadow DOM**：B站等自研播放器把 `<video>` 放在影子根里，普通查询扫不到，脚本会一并识别
- 实时应用到所有 `<video>` 元素
- 新增 video 元素通过 MutationObserver 自动应用

### B 站画质解锁
- **未登录状态**解锁 B 站 1080P 画质选项（拦截播放器 API 注入 VIP 画质字段）
- 属于灰色功能，依赖 B 站播放器接口，改版可能失效
- 不影响其它屏蔽功能

### YouTube 旋转 / 翻转 / 填充
- **旋转**：90° / 180° / 270°
- **翻转**：水平 / 垂直
- **填充**：自定义宽高比（如 21:9 / 32:9 电影级填充）
- 通过 `Ctrl + Shift + Y` 快捷键触发
- 实现原理：CSS transform 应用到 `<video>` 元素

## ☁️ WebDAV 同步（自建云端）

> 💡 **数据安全模型**：脚本配置在本地用你的 WebDAV 密码做**异或（XOR）加密**后才上传到你的服务器，开发者拿到的是密文。

### 支持的 WebDAV 服务
- **坚果云**（国内访问稳定，有免费 1GB 空间）
- **自建 Nextcloud**（完全自主可控）
- **自建 Seafile**（开源网盘）
- **任何标准 WebDAV 服务**

### 配置步骤
1. 设置 → WebDAV 同步 → 填入服务器地址（如 `https://dav.jianguoyun.com/dav/`）
2. 填入用户名 + 密码
3. 测试连接
4. **上传到云端** / **从云端下载**

### 加密机制（诚实说明）
- 配置经 **XOR 异或加密**（`xorCrypt`，密钥 = 你的 WebDAV 密码），再加 Base64 编码后上传
- 这是一种**基础混淆**，能让传输内容不直接可读；相对更强的方案是自建 HTTPS 服务器
- 请勿把 WebDAV 密码当作高强度密钥使用；务必只在可信的自建/知名 WebDAV 服务上同步
- 记住密码即可正常同步；忘记密码则本地概览无法恢复已同步配置

<a id="config-contract"></a>
## 🧩 配置格式与兼容性（契约）

> 这一节是**对用户数据的承诺**，也是后续改版必须遵守的规则。改 UI 布局、加功能、重构面板都不该让你丢配置。

### 五条承诺

1. **配置按 key 存储，与面板布局无关**
   分组叫什么、排第几个、拆成几栏，都不影响数据 —— 所以以后重排面板（比如把 linux.do 并进社区增强）**不会**让任何开关「变回默认」。

2. **只增不改**
   新功能可以随时加 key；既有 key **永不重命名、永不删除**。要取代某个 key，就同时保留它并兼容读取，让你升级后行为连续。

3. **未知字段一律保留**
   新版导出的文件导进旧版，旧版**不认识也会原样存着**。所以「新版 → 旧版 → 再导出」这条链路不会把新字段吃掉；等你再升回新版，那些配置又生效了。

4. **结构变更必须升 schema + 写迁移**
   只是加字段（绝大多数情况）→ schema 不动，靠默认值补齐。
   改变层级/类型/语义 → schema +1，并在迁移链里补一条，老配置导入时自动升级。

5. **导入与云同步走同一个入口**
   文件导入、云端恢复、配置历史回滚共用一套解析逻辑，不存在「文件导入正常、云同步丢字段」这种分叉。

### 导出文件长什么样

```json
{
  "_nc": {
    "app": "NetClean",
    "schema": 1,
    "version": "1.5.1",
    "exportedAt": 1761799999999
  },
  "baidu": { "uiTheme": "dark", "adBlock": true, "...": "..." },
  "siteScopeList": ["gov.cn"],
  "pingbikw": ["广告词"]
}
```

- `_nc` 是**信封**，不参与配置合并；顶部 key 按字母序排列，方便版本间 diff。
- 没有 `_nc` 的老文件（v1.5.1 之前导出的）自动视为 `schema: 1`，照常导入。

### 兼容矩阵

| 场景 | 结果 |
|---|---|
| 旧配置 → 新版 | ✅ 缺的新字段**补默认值**，已有的原样保留，必要时按迁移链升级 |
| 新配置 → 旧版 | ✅ 能导入；不认识的字段**保留不删**，旧版读不到、不会报错（导入时会提示"配置来自更新版本"） |
| 再导回新版 | ✅ 之前"读不到"的字段因为一直存着，会**重新生效** |
| 改面板布局 / 分组 / 顺序 | ✅ 完全无影响（按 key 存） |
| 导入非配置文件 | ⛔ 明确报错并中止，**不会**清空你的现有配置 |

### 导入时会提示什么

- 配置来自更高版本 → 「新增字段会完整保留，但本版本暂时读不到」
- 配置来自旧版本 → 「已按迁移链升级」
- 保留了本版本不认识的字段 → 「保留了 N 个未知字段，不会被删除」

看到这几条属正常，不是错误。

## 🛡️ 站点级生效范围（一个模式 + 一份名单）

> 📋 在 **设置 → 📋 名单管理 → ① 站点级 · 生效范围** 里维护，支持 **txt / csv 批量导入**（详见 [设置面板详解](#-设置面板详解)）。

一份名单、一个三态单选，回答的其实是同一个问题 ——「脚本到底在哪些站点跑」：

| 「生效范围」模式 | 含义 | 名单的作用 |
|---|---|---|
| **全部站点**（默认） | 所有站点都运行 | 名单被忽略（面板会提示「名单内有 N 条，当前模式不使用」） |
| **仅名单内生效** | 只有**名单内 + 内置已知站点**会运行，其余页面注入后秒退（近零开销） | 这是一份「允许运行」的名单 |
| **名单内不生效** | **命中名单的站点整站暂停**：脚本完全不介入，不注入任何净化 / 美化 / 划词 / 验证码 | 这是一份「禁止运行」的名单 |

- 匹配规则是「当前域名包含该条目」，填 `baidu.com` 即覆盖其全部子域
- 「仅名单内生效」下，内置已知站点（百度 / Google / 知乎 / B站 / 微信 …）**始终放行**，不必写进名单
- 油猴 `@match` 是静态元数据、无法运行时切换，此项通过**启动后早退**实现
- ⚠️ 改动模式或名单后**需刷新页面**才生效（判定发生在脚本启动早期）
- 命中的站点右下角会出现「⏸ 本站已暂停」徽标，点开即为急救面板，可一键解封或改回「全部站点」
- 想快一点：油猴菜单 **「🚫 只暂停当前网站」** / **「▶️ 恢复当前网站」** 会把本站直接加进 / 移出这份名单，并自动把模式切到「名单内不生效」

> 说明：v1.1.0 起，原「暂停名单 + 启用暂停名单开关」与「仅在名单内网站运行 + 开关」这两套**方向相反、各带一份名单**的机制，已合并为本表这一套「一个模式 + 一份名单」（即评审表里的 A4）。旧配置字段（`whiteurl` / `scopeWhitelist` / `perfWhitelist` / `scriptBlacklist`）与其迁移代码**整体删除**、不做数据搬迁 —— 合并后这些字段已无人读取。

## ❓ 常见问题 FAQ

### Q1: 安装后页面没变化？
A: 检查三件事：
1. 油猴扩展是否启用（地址栏右侧图标）
2. 是否允许脚本在「私密窗口」运行（部分浏览器默认禁止）
3. 设置 → ① 组 → 「通用防护」是否全部启用
4. 刷新页面（部分功能需 DOM 重建后生效）

### Q2: 某个站点的拦截失效了？
A: 大概率是站点改版了。可在 [GitHub Issues](https://github.com/bigoceans/netclean/issues) 报告，附上：
- 站点 URL
- 期望拦截但没生效的元素（截图）
- 控制台报错（按 F12 → Console）

### Q3: 护眼模式没有「滤蓝光」效果？
A: 详见上文 [护眼模式（科学诚实版）](#-护眼模式科学诚实版) 章节。
multiply 蒙版**不改变屏幕蓝光发射量**，真正的护眼请配合 OS 级（Windows Night Light / macOS Night Shift / f.lux）。

### Q4: 视频看起来反色了？
A: 这是 multiply 蒙版 + 特定视频滤镜同时开启的极端组合。
- 方案 1：临时关闭护眼模式（`Ctrl + Shift + P`）
- 方案 2：护眼强度调为「柔和」
- 方案 3：护眼色改为「淡橄榄绿」

### Q5: 怎么完全卸载？
A: 油猴菜单 → 仪表盘 → 找到「全网净化大师」→ 点击垃圾桶图标。
所有数据保存在油猴沙箱，卸载时自动清除。

### Q6: 会影响我浏览器的隐私模式吗？
A: 默认**不会**。如需在隐私窗口生效：
- Chrome：扩展详情页 → 允许在隐身模式运行
- Firefox：about:addons → 此扩展 → 在隐私窗口中运行

### Q7: 配置丢了怎么恢复？
A: 三种方案：
1. WebDAV 同步：从云端下载（前提是你开过同步）
2. 浏览器同步：如果你用 Chrome / Edge 且开启了浏览器数据同步，油猴配置可能跟随
3. 重新手动配置（无备份就只能这样了）

### Q8: 能和 uBlock Origin / AdGuard 同时使用吗？
A: 完全可以，且**推荐同时使用**。本脚本专注于**搜索净化 + 划词 + 视频增强**等场景化功能，与通用广告拦截器不冲突，反而互补。

### Q9: 在手机浏览器能用吗？
A: iOS Safari 通过 [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) 可用；
Android 推荐 [Kiwi Browser](https://kiwibrowser.com/) + Tampermonkey。
**桌面体验最佳**。

A: 欢迎 PR / Issue！

- Issue：报告 bug / 提功能建议
- PR：fork → 改 → PR（请附 verify 脚本 + 截图）

界面重构版 —— 控制面板重绘为「配色令牌 + 明暗双主题」，左栏底部改为语言 / 明暗双联开关，并修掉一批「点了没反应」的控件。

**🎨 界面**

- **对比度重做**：输入框 / 下拉 / 开关轨道 / 复选框全部加可见描边与更深的文字色，不再是「白底白字」。
- **下拉框自绘**：原生 `<select>` 的系统弹层（方角 + 系统蓝）无法改样式，改为「原生 select 作数据源 + 自绘圆角浮层」，支持键盘上下键 / Esc / 点外部关闭。
- **底栏改浮动模块**：自动保存栏从通栏直角条改为圆角悬浮卡片，与内容区不再有硬直线拼接。
- **「本页体检」替代「近期更新」**：原来那三个版本的摘要**写死在脚本里**，每次发版都要手工同步（漏一次就出现「已是 1.5.0，关于页还写 1.4.0 当前」）。现在第三瓣改为实时读取本机状态：是否生效 / 当前域名 / 生效范围 / 已启用功能数 / 本次与本站拦截数 / 最近 3 条错误，并提供「复制诊断报告」与完整的更新日志入口 —— 零网络请求、零维护。
- **关于页**：三瓣圆盘改为 117°×3 + 3°×3 等大等缝（消除「紫色压蓝色」）、标签沿扇形切线斜排；圆心详情重排为「一句导语 + 三张信息卡」，删掉冗余长段落；再点侧栏「关于」回到圆盘首页。
- **文案收敛**：面板公共区域不再罗列「支持 XX 站点」，站点清单只写在更新文档里。
- **夜间补全**：帮助弹层、划词引擎表 / 视频下载 / 配置同步 / 名单 / 关于数据看板的卡片与按钮、以及确认框 / 云备份管理 / 配置历史三个 body 级弹窗全部纳入夜间配色（原来这些是写死的浅色，切夜间仍是一块白）。

**🐞 修复**
- **「导入预设敏感站点 / 清空名单」点了没反应**：批量按钮渲染在卡片层，代码却在 `.zk-set-list` 内部找按钮 → 一个监听都没挂上。改为从卡片作用域查，并补回归断言。
- **繁体漏转**：简→繁字表只收了 286 字（与 / 键 / 项 / 拦 / 势 / 馈 / 据 / 滤 / 划 / 脱 等都没转）。改用离线生成的 2741 字完整字表 + 12 条词级例外（复制→複製、干净→乾淨、重复→重複…）；底部统计、看板切天数、关于详情标题这些「扫描之后才渲染」的文本也补了转繁通道；面板根重置 `text-align`，避免站点 `body{text-align:center}` 漏进来把文案顶到中间。
- **修复「一起跟随」失效**：控制面板切明暗后，划词工具条与翻译面板纹丝不动 —— 根因是写入层（`baidu` 命名空间）与运行期读取层（配置根层 `selSearchTheme`）不一致。现已统一到根层，并让面板「工具栏外观」的主题下拉与预览立即同步（不会再出现「已选深色、面板还显示浅色」）。

- **实时预览**：外观设置下方新增预览块（模拟网页背景上的迷你工具条 + 翻译卡），改参数即时看到效果，不用反复开关面板试。
